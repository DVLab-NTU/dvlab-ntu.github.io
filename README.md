# DVLab Website — Design Verification Lab, NTUEE

The official website of the Design Verification Lab (DVLab) at National Taiwan
University, directed by Prof. Chung-Yang (Ric) Huang. Bilingual (Traditional
Chinese default at `/`, English at `/en/`), statically generated with Astro,
with automatic dark mode and full per-page SEO.

Live site: <https://dvlab-ntu.github.io/>

## Stack

- [Astro](https://astro.build) 5 — static site generation (every route is a
  real HTML file: no client-side rendering, all pages return 200)
- Content: Markdown with frontmatter under `src/content/` (members, papers,
  courses, awards, join) — bilingual `zh`/`en` fields
- Dark mode: automatic via `prefers-color-scheme` + manual toggle
  (localStorage `lab-theme`), FOUC-safe inline script
- SEO: per-page title/description/canonical/hreflang/OG generated by
  `src/layouts/BaseLayout.astro`, verified by `npm run test:seo`
- Sitemap: `@astrojs/sitemap` (generated at build time)

## Local development

```bash
npm ci
npm run dev          # dev server with content hot reload
npm run preview      # preview the production build
```

## Verification

```bash
PUBLIC_SITE_URL=https://dvlab-ntu.github.io npm run verify
```

Runs: content validation → production build → smoke checks → SEO/i18n checks.
CI runs the same command; GitHub Pages deploys only after it passes.

## Content

| Collection | Path | Notes |
|---|---|---|
| Members | `src/content/members/*.md` | `id` must match filename; `name`/`role`/`area`/`bio`/`status` are `{zh, en}` objects; `links` supports scholar/github/homepage/email/linkedin; avatar auto-resolves from `public/member/images/<id>.jpg` |
| Papers | `src/content/papers/*.md` | `year`, `title`, `venue`, `authors`, optional `abstract`/`links`/`bibtex` |
| Courses | `src/content/courses/*.md` | `title` `{zh,en}`, `semester`, official `link`, optional `intro`/`contents` `{zh,en}` |
| Awards | `src/content/awards/*.md` | `title` `{zh,en}`, `year`, `month`, `students[]`, optional `advisors[]`, `source` URL |
| Join | `src/content/join/recruitment/` | `overview_cn.md` / `overview_en.md` |

Site-wide copy (brand, nav, home hero/highlights): `src/data/site.zh.json` and
`src/data/site.en.json`.

Member photos: `public/member/images/<id>.jpg` (resolved by avatar field or
name fallback in `src/utils/member-avatar.ts`).

## Deployment

`.github/workflows/pages.yml` builds, verifies, and deploys `dist/` to GitHub
Pages at <https://dvlab-ntu.github.io/>. `sitemap-index.xml` is generated
automatically. The `admin/` route is an optional Decap CMS backend (disabled
until `CMS_GITHUB_REPO` / `CMS_OAUTH_BASE_URL` are configured).
